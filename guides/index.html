实用指南

这里放一些网络工具最容易看错、选错的地方：测速数字怎么读、DNS 怎么选、游戏卡顿从哪里查，以及隐私设置该注意什么。

测速结果到底怎么看：下载、上传、Ping、抖动别混在一起

测速页面上的几个数字看着简单，但最容易误解的是把“下载速度快”等同于“网络一定好”。

VPN 和网络加速器有什么区别？先看你想解决哪类问题

这两个词经常被放在一起，但它们解决的问题并不完全相同。

公共 DNS 怎么选：别只盯着“哪个最快”

公共 DNS 的差别不只在速度。有些强调隐私，有些提供恶意域名过滤，有些可以自定义拦截策略。

Wi‑Fi 还是网线？玩游戏和视频会议怎么选

如果设备位置允许，网线通常更容易得到稳定结果；但现代 Wi‑Fi 在环境干净、信号良好时也完全能满足多数日常场景。

网络丢包是什么意思？什么时候该认真处理

丢包就是数据包没有按预期到达。偶发一次和持续丢包不是一回事，真正影响体验的是频率、持续时间和发生位置。

网络抖动是什么？为什么 Ping 不高也会卡

平均延迟不高，但每个数据包到达时间忽快忽慢，体验仍然会很差，这就是抖动最麻烦的地方。

DNS 泄漏测试怎么看：看到陌生解析器不一定就是“泄漏”

DNS 泄漏测试能帮助你观察当前域名请求走向哪里，但结果需要结合你的网络设置和所用服务来解释。

IPv6 到底要不要开？先确认网络是不是稳定支持

IPv6 不是“越新越快”的开关，它首先解决地址空间和网络架构问题。是否开启，更应该看你的运营商、路由器和设备支持是否稳定。

公共 Wi‑Fi 能不能用？能，但别把它当自己家网络

公共 Wi‑Fi 最大的问题不是“连上就一定被黑”，而是你无法完全了解接入点、同网段用户和网络管理策略。

浏览器会暴露哪些网络信息？从 IP、WebRTC 到指纹

浏览器为了正常工作会暴露一定的设备和网络信息。真正需要关注的是这些信息能不能被组合成稳定的识别特征。

Ping 多少算正常？没有一个适合所有场景的数字

20ms、50ms、100ms 经常被拿来划线，但真正应该看的是场景和稳定性。

Traceroute 怎么看？它更适合找“在哪一段变差”

Traceroute 不是用来证明“某一跳就是故障”的简单工具，它更适合观察网络路径、路由变化和延迟从哪一段开始持续上升。

测速 500Mbps，下载为什么只有 20MB/s？先看单位和服务器

测速与下载速度不一致非常常见，最先检查的是 Mbps 和 MB/s 的单位差异。

网速很快，为什么一有人下载游戏全家都卡？可能是 Bufferbloat

带宽跑满时，路由器或链路队列积压会让延迟突然升高。测速很快但游戏、语音同时变卡，Bufferbloat 是值得检查的一项。

远程访问公司网络，VPN、零信任和组网工具怎么分

远程访问不只一种做法。传统 VPN、零信任访问和基于 WireGuard 的组网工具各有侧重点。

临时传大文件，网盘、点对点和临时链接怎么选

“发个大文件”背后其实有三种常见需求：长期保存、临时分享、设备之间直接传。

网站打不开，是自己网络坏了还是网站挂了？

遇到单个网站打不开，最省时间的不是马上改 DNS，而是先判断问题范围。

HTTPS 小锁不等于“这个网站绝对安全”

HTTPS 主要保护浏览器与网站之间的传输并验证证书身份，它不能保证网站内容本身可信。

公网 IP、内网 IP、出口 IP，一次分清

很多“我的 IP 是什么”其实混了三种概念：设备在局域网里的地址、运营商出口地址，以及网站实际看到的来源地址。

DoH、DoT 是什么？它们加密的是 DNS，不是全部流量

DNS over HTTPS 和 DNS over TLS 都是加密 DNS 查询的方式，但不要把它们和完整 VPN 混为一谈。

看 VPN 隐私说明时，别只找“无日志”三个字

“No logs” 经常出现在 VPN 宣传里，但真正有用的是看它具体指哪些数据、是否有独立审计，以及政策是否写得清楚。

游戏延迟突然变高，先别急着换工具

以前正常、突然变高，和一直都高是两种问题。先确认“什么时候开始、只有这个游戏吗、其他设备也这样吗”。

改了 DNS 但没生效？可能只是缓存还在

更换 DNS 后立刻测试，有时仍会看到旧结果，因为浏览器、系统、路由器和解析器都可能缓存记录。

网站出问题时，我通常先开这几个网络工具

排查网站故障时，把工具按问题类型分组，比收藏几十个链接更实用。

下载网络工具前，先做这几个简单检查

网络工具经常需要较高权限，尤其是 VPN、抓包、远程访问和代理软件。安装前花一分钟检查来源，比事后排查省事。
