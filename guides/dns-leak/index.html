DNS 泄漏测试怎么看：看到陌生解析器不一定就是“泄漏”

DNS 泄漏测试能帮助你观察当前域名请求走向哪里，但结果需要结合你的网络设置和所用服务来解释。

先理解“泄漏”指什么

DNS 泄漏测试通常是在看：你发出的 DNS 查询最终到了哪些解析器。如果你本来希望所有查询都走某个 VPN 或指定 DNS，却仍出现运营商解析器，才值得继续排查。

看到陌生公司名不一定有问题

很多 DNS 服务会使用第三方网络、Anycast 或不同的运营主体名称。测试页面显示的组织名和你设置里看到的品牌不完全一致，并不能单独证明发生泄漏。

测试时要保持条件一致

先确认 VPN 或加密 DNS 已经连接，再开无痕窗口或清理旧连接影响，连续测两次。若结果持续出现不该出现的解析器，再检查系统 DNS、浏览器 DoH 和 VPN 的 DNS 设置。
