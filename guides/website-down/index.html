网站打不开，是自己网络坏了还是网站挂了？

遇到单个网站打不开，最省时间的不是马上改 DNS，而是先判断问题范围。

网站打不开时，从症状选择下一步 →

先判断是不是只有你打不开

先打开两个平时能正常访问的网站。如果全都打不开，优先检查本机 Wi-Fi、有线连接、路由器和宽带。如果只有一个域名打不开，用手机切换到移动数据再试，并请另一位不同网络的用户确认。多个网络都打不开，才更有理由怀疑站点自身故障。

根据浏览器提示定位下一步

提示“找不到服务器”或 DNS 相关错误，先检查域名是否拼写正确，再用 DNS 查询工具确认是否存在解析记录。提示“连接超时”，可能是网络路径、服务器响应或防火墙限制；提示 403、404、500 时，请区别权限限制、页面不存在和服务器错误，不要统一归因于 DNS。

用外部检测工具交叉验证

通过 Check-Host 等多地区检测服务测试同一 URL。若部分地区正常、部分地区失败，可能与区域节点、CDN、网络策略或解析差异有关，不能凭一次结果断言全球宕机。优先保留出错时间、完整 URL、错误文案和所在网络类型。

什么时候应该联系网站或网络服务商

如果多个独立网络都不能打开同一网站，可将错误页面和时间发给网站管理员；如果只在家里宽带失败、手机移动数据正常，再检查路由器、DNS 和运营商网络。不要未经判断就反复清理缓存或安装所谓“修复软件”。

可以先记下完整的 URL、报错时间、是否使用 VPN，以及 Wi-Fi 与移动数据下的差异；这些信息比一句“网站打不开”更能帮助定位。

DNS 解析失败：先核对域名，再查 A/AAAA 或 CNAME 记录。连接超时：检查目标端口、网络路径或服务端防火墙。证书错误：核对访问域名、证书有效期与设备时间。HTTP 403、404、500：分别从权限规则、页面路径和服务器日志排查；这些状态码本身说明请求已经到达某个 HTTP 服务。
