网站出问题时，我通常先开这几个网络工具

排查网站故障时，把工具按问题类型分组，比收藏几十个链接更实用。

网站排查工具最好按问题来选

查 DNS 用 dig/在线 DNS 查询，查 TLS 配置用 SSL Labs，查页面性能用 PageSpeed Insights 或 WebPageTest，查 HTTP 头用 curl 或专门的 Header 工具。一个网站没必要包办所有检查。

自动评分只是线索

性能、安全 Header 或 页面检查工具给出的分数很适合发现问题，但不是业务目标本身。比如缓存策略、第三方脚本和安全策略都可能有合理例外。

重要变更要回到官方文档

浏览器、安全标准和搜索平台规则都会更新。涉及部署参数时，工具报告用来定位，最终配置以对应平台和标准文档为准。
