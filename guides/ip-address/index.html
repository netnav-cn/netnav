公网 IP、内网 IP、出口 IP，一次分清

很多“我的 IP 是什么”其实混了三种概念：设备在局域网里的地址、运营商出口地址，以及网站实际看到的来源地址。

公网 IP 和内网 IP 不是一回事

家里设备常见的 192.168.x.x、10.x.x.x 属于私有地址，只在本地网络中使用。网站看到的通常是运营商分配给你出口的公网地址，或者运营商 NAT 后的共享出口。

为什么公网 IP 会变化

很多家庭宽带和移动网络使用动态分配，断线重连或运营商调整后地址可能改变。固定公网 IP 一般需要专门的业务或配置。

查询结果别过度解读

IP 地理位置通常只能估算到城市或区域，数据库也可能过时。它适合判断运营商、ASN 和大致地区，不适合当成精确住址。

一分钟分清设备地址与网站看到的地址

  1. 在设备网络设置中找到 IPv4/IPv6 地址，记下当前连接使用的是 Wi-Fi 还是有线网络。
  2. 再打开 IP 查询工具查看网站看到的出口地址。
  3. 如果两者不同，通常是路由器或运营商执行了地址转换；使用代理或 VPN 时，查询结果也可能是代理出口。

例如电脑拿到 192.168.1.12，IP 查询网站显示另一个地址，这并不意味着账号被盗。前者用于家庭局域网，后者是对外通信中可见的地址。

查询 IP 能判断什么，不能判断什么

IP 查询可辅助判断网络出口、运营商和大致地区。地理定位数据库会存在误差，不能据此认定设备的街道地址。若要判断是否存在 IPv6 出口，参考IPv6 连通性检查；若关注隐私暴露，继续查看浏览器可能泄露的信息。
