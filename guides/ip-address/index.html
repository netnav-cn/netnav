公网 IP、内网 IP、出口 IP，一次分清

很多“我的 IP 是什么”其实混了三种概念：设备在局域网里的地址、运营商出口地址，以及网站实际看到的来源地址。

公网 IP 和内网 IP 不是一回事

家里设备常见的 192.168.x.x、10.x.x.x 属于私有地址，只在本地网络中使用。网站看到的通常是运营商分配给你出口的公网地址，或者运营商 NAT 后的共享出口。

为什么公网 IP 会变化

很多家庭宽带和移动网络使用动态分配，断线重连或运营商调整后地址可能改变。固定公网 IP 一般需要专门的业务或配置。

查询结果别过度解读

IP 地理位置通常只能估算到城市或区域，数据库也可能过时。它适合判断运营商、ASN 和大致地区，不适合当成精确住址。
