临时传大文件，网盘、点对点和临时链接怎么选

“发个大文件”背后其实有三种常见需求：长期保存、临时分享、设备之间直接传。

先选适合的传输方式

同一办公室或家庭网络中的设备互传文件，可以优先考虑局域网或系统自带共享；跨城市发送少量文档，云盘共享链接更方便；批量大文件或敏感资料，则应考虑断点续传、访问权限和端到端加密是否真的得到支持。

发送之前检查四件事

确认接收方身份、允许访问的用户范围、链接是否有过期时间、对方是否必须登录。公开共享链接不要混入身份证件、密码和公司内部文件；如果必须传输敏感资料，应先确认服务协议和加密方式。

大文件传输失败怎么办

先排除单个文件大小限制与可用空间不足，再检查网络中断后能否恢复。如果服务支持断点续传，优先使用官方客户端，不建议将敏感文件上传到来源不明的在线“中转站”。

怎么确认文件没有损坏

重要的安装包、备份或交付文件可以对比发送前后的 SHA-256 摘要。校验值一致可以提高文件完整性的信心，但不能单独证明文件安全或来源可靠。

三种场景怎么选

同一局域网中传照片，可先考虑本地传输方案，减少跨网中转。给外部联系人共享非敏感文档，云盘链接通常更方便；传大型备份，先确定是否支持断点续传、校验以及失效后重试。

如何核对文件完整性

Windows PowerShell 可以执行 `Get-FileHash .\archive.zip -Algorithm SHA256`；macOS 和 Linux 可执行 `shasum -a 256 archive.zip`。发送方和接收方对比摘要即可判断文件内容是否一致，但哈希相同不能证明文件一定无恶意程序。
