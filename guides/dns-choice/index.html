公共 DNS 怎么选：别只盯着“哪个最快”

公共 DNS 的差别不只在速度。有些强调隐私，有些提供恶意域名过滤，有些可以自定义拦截策略。

DNS 不是越“快”越好

公共 DNS 的差别除了解析延迟，还包括隐私政策、恶意域名过滤、家长控制、ECS 处理方式和可用地区。对普通用户来说，稳定和可解释通常比一次测试快 3ms 更重要。

先看自己的需求

只想要基础解析，可以从运营商 DNS、Cloudflare、Google Public DNS、Quad9 等常见服务里选；需要广告或恶意域名过滤，则要看提供过滤策略的服务。公司网络则应优先遵循管理员配置。

别用一次测速决定长期配置

DNS 延迟会随地区、运营商和时间变化。连续测试、观察失败率，比只看某次最快结果可靠。更换后如果网页或应用出现异常，也要考虑 CDN 定位和公司内网域名解析。

公共 DNS 也可能影响 CDN 体验

有些内容分发网络会根据 DNS 请求来源或其他网络信号选择节点。更换解析器后，偶尔会出现“解析很快，但实际下载不一定更快”的情况。所以选 DNS 时别只跑解析延迟测试，也要观察常用网站和应用有没有异常。

家庭网络怎么选比较省心

如果现在没有解析故障，其实不必为了几毫秒频繁更换。要换的话，一次只改一个地方，记录原设置，并连续用几天观察稳定性。出现公司内网域名打不开、智能设备异常时，优先恢复原配置再判断。

选 DNS 前先做两次查询

先用当前网络打开一个经常访问的网站，记录是否存在解析失败；再用 nslookup example.com 查看系统默认解析结果。若要比较指定解析器，可用 nslookup example.com 1.1.1.1 与 nslookup example.com 8.8.8.8 分别查询。结果 IP 不同未必代表有故障：CDN、地域和缓存都可能影响答案。这里的地址仅用于演示，实际选择仍要考虑所在地网络、过滤需求及服务条款。

更改 DNS 后，如果公司内网域名打不开，应先还原原配置验证，不要把公共解析器强行用于需要内部 DNS 的网络。

可以先看 DNSChecker 的多地区查询，再按 DNS 缓存排查步骤区分旧缓存和配置错误。

顺手做个实际检查

想把几种常见方案放在一起看，可以从这些官方入口开始：

  • Cloudflare 1.1.1.1
  • Google Public DNS
  • Quad9
  • NextDNS

改了 DNS 但查询仍是旧地址？

先分清“换了解析器”和“域名记录刚改动”。前者要核对设备当前实际在向哪个 DNS 服务器发问；后者要检查权威记录、TTL 与递归解析器缓存。遇到第二种情况，直接参考DNS 缓存与记录更新的排查步骤，不要为了看见新 IP 一直切换公共 DNS。
