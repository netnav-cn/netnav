DoH、DoT 是什么？它们加密的是 DNS，不是全部流量

DNS over HTTPS 和 DNS over TLS 都是加密 DNS 查询的方式，但不要把它们和完整 VPN 混为一谈。

DoH 和 DoT 只保护 DNS 这一步

DoH 把 DNS 查询放进 HTTPS，DoT 则使用专门的 TLS 连接。两者都可以减少本地网络直接看到明文 DNS 查询的机会，但它们不会自动把所有网页、应用流量都变成 VPN 隧道。

为什么浏览器和系统设置可能不一致

有些浏览器自带 DoH，可以覆盖系统的普通 DNS；企业网络也可能通过策略指定解析方式。排查时要分别看浏览器、操作系统和路由器，而不是只改一处。

什么时候适合开启

公共网络、希望减少本地 DNS 明文暴露时很实用。公司网络、家长控制或依赖内部域名的环境，则应先确认管理员要求，避免绕过必要的内部解析。
