改了 DNS 但没生效？可能只是缓存还在

更换 DNS 后立刻测试，有时仍会看到旧结果，因为浏览器、系统、路由器和解析器都可能缓存记录。

先搞清楚是谁在缓存

改 DNS 后还看到旧结果，不一定是设置失败。浏览器、操作系统、路由器以及上游解析器都可能保存 DNS 结果，域名记录本身也有 TTL。

什么时候值得清缓存

域名刚迁移、解析记录刚修改，或者你正在确认新的 DNS 设置是否生效时，清理本机缓存比较有用。平时没问题时没必要把清缓存当成“网络加速”步骤。

TTL 不是本机能强行跳过的

就算本地缓存已经清掉，上游递归解析器仍可能在 TTL 到期前返回旧记录。碰到这种情况，等一段时间再查，通常比反复重启路由器更有效。

怎么验证最省事

先用系统或命令行查看当前解析结果，再用一个独立 DNS 查询工具做对照。如果两边都已经返回新地址，说明问题大概率不在 DNS 缓存。
