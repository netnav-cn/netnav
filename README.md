# NetNav 网络工具导航

[访问网站](https://netnav-cn.github.io/netnav/)

NetNav 是一个中文网络工具导航网站，提供网络测速、DNS 与 IP 查询、网络诊断、隐私检测、开发调试、网站监控和远程办公等工具入口，以及相关使用指南。

## 功能

- 按用途浏览网络工具与服务
- 通过站内搜索查找工具、分类和指南
- 阅读工具使用说明与网络问题排查指南
- 响应式深色科幻主题，支持桌面和移动端浏览

## 本地运行

项目使用 HTML、CSS 和原生 JavaScript，无须安装依赖或执行构建命令。

```bash
python -m http.server 8000
```

在浏览器打开 <http://localhost:8000/> 即可预览。

## 项目结构

```text
assets/          样式、脚本、图标与图片
categories/      工具分类
sites/           工具介绍
guides/          使用指南
data/            站内搜索数据
about/           关于页面
privacy/         隐私说明
disclaimer/      免责声明
index.html       网站首页
robots.txt       爬虫访问规则
sitemap.xml      网站地图
```

## V28 搜索优化

- 全站搜索支持空格分隔的多关键词，关键词可分散出现在名称、分类和描述中；所有词都须匹配。
- 结果按名称精确匹配、前缀匹配、名称包含、分类及说明依次加权，并显示总匹配数（最多展示 30 条）。
- 搜索面板打开时按 Ctrl/⌘+K 将焦点定位回搜索框；Esc 关闭弹层；Tab 限制在弹层内。
- 原有 URL、canonical、robots、站点数据与推广素材未改动。


### V30 交互改进
- 已打开搜索时重复按搜索快捷键不会重置结果或发起新的请求。
- 搜索结果使用上下方向键导航；到首尾后可返回输入框，方便修改检索词。
- 分类筛选框按 Escape 可清空当前关键词，并提供无结果提示。
- 搜索和分类输入加入清晰的键盘焦点样式，以及减少动态效果的偏好适配。


## V31 搜索交互优化
