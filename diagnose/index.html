三个容易混淆的情况

能 Ping 通，不代表网站正常

Ping 主要检查 ICMP 响应。目标可能禁用 ICMP，也可能网页服务自身出了问题，需要结合 HTTP 检测。

测速快，不代表玩游戏不会卡

下载吞吐量与抖动、丢包和满载延迟是不同指标。问题发生在上传占满带宽时，可以进一步看 Bufferbloat。

IP 变了，不代表没有 DNS 泄漏

需要比较连接前后的 DNS 解析器，并留意操作系统和浏览器各自的加密 DNS 设置。
