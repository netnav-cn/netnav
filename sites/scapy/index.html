Scapy

Python 网络数据包构造与分析工具。

核心用途：Scapy 是 Python 网络数据包处理工具，可构造、发送、捕获和解析多种协议的数据包，用于协议学习、实验与授权网络诊断。

适合需要自定义协议数据包时

在受控实验网络中组合 IP、TCP、UDP 等协议字段，观察响应与抓包结果；如果只是检查网页 HTTP 请求，浏览器开发者工具或专用 API 客户端通常更直接。

留意权限、网卡与抓包范围

发包和抓包功能可能需要系统权限，也受到操作系统及网络环境限制。避免在未授权的网络执行扫描或构造干扰性数据包，保存报文时注意清理令牌和其他敏感载荷。
