它提供的是什么

OpenDNS 是 DNS 解析服务及相关安全过滤方案的品牌。其作用是为域名返回解析结果，并在特定服务与配置下应用过滤规则；不是用来查询任意 IP 归属地或 ASN 的工具。

使用前先选服务类型

个人网络与组织管理场景可能使用不同服务及设置方式。先在官方资料中确认解析器地址、可用功能和当前的产品范围，再进行配置，避免把过滤能力当作所有模式的默认功能。

配置后怎么检查

记录原 DNS 设置，修改后访问常用网站测试解析结果，必要时检查系统和浏览器是否分别配置了 DNS。若出现特定域名异常，先对比不同解析器结果，再判断是否与过滤策略有关。

隐私与网络性能的边界

DNS 解析器可以看到交给它处理的查询；普通 DNS 也不等于加密连接。更换服务不能直接解决路由拥塞或无线网络不稳定。
