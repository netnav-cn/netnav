别只看“隐私”两个字

Tor Browser 放在“VPN 与隐私”里更好理解。它的主要用途是Tor 官方浏览器下载入口。如果这正是你要解决的问题，Tor Browser 可以直接继续看官方入口。

Tor Browser 的功能表之外，还要看这些边界

Tor Browser 是否适合，通常取决于设备支持、连接方式和隐私条款。把这些和你的真实需求对上，比只看宣传词更实际。
