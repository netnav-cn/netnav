它是什么

Tor Browser 是 Tor Project 维护的浏览器，重点是通过 Tor 网络访问网站并减少可被关联的浏览器特征。它不等于为设备所有应用开启 VPN，也不能保证绝对匿名。

何时值得使用

需要尽量减少网站对来源网络的直接识别、关注浏览行为关联风险时，可以了解 Tor Browser。由于经过多个节点，访问体验和可用性可能不同于普通浏览器，部分网站也会要求额外验证。

使用时要注意

从 Tor Project 官方下载并保持更新；不要以为使用 Tor Browser 就能消除自己主动登录账号、上传身份资料所带来的关联风险。隐私取决于浏览器之外的行为和环境。

与 Tor Project 的关系

Tor Project 是维护 Tor 网络及相关软件的组织和项目；Tor Browser 是其中面向终端用户的浏览器产品。
