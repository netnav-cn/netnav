先选对应的检测项目

BrowserLeaks 集成浏览器指纹、WebRTC、Canvas、DNS 等多种检查。想确认公网 IP 或 WebRTC 暴露，应选择对应测试；这些项目反映不同机制，不存在一项分数能够概括所有隐私风险。

如何比较浏览器设置

先记录浏览器版本、扩展和网络出口，再只改变一个设置进行复测。如果同时更换 VPN、浏览器和多个扩展，即使结果不同也难以判断是哪一个因素造成。

检测结果的限制

浏览器能显示多个网络地址或具有可识别特征，不代表已经泄漏个人身份；反过来，即便 IP 没有暴露，也不意味着完全无法被追踪。应结合实际威胁模型理解测试。
