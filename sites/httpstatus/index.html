HTTPStatus

批量检查 HTTP 状态码与重定向。

适合做什么：查看 HTTP 响应状态与重定向链，适合排查页面跳转或错误状态。

检查跳转链

输入目标 URL，确认最终返回 200、301、302、404 等何种状态，以及中途跳转了几次。检查是否从 HTTP 正确切换到 HTTPS，是否出现循环或错误跳转。

状态码不能解释全部问题

HTTP 200 不代表页面内容一定正确，重定向也不必然是错误。遇到 SEO 收录或访问问题，需结合响应头、Canonical 和实际页面内容判断。
