用命令行抓取特定流量

先确认网卡名称，然后按主机、端口或协议过滤；例如 `sudo tcpdump -i eth0 -nn host 192.0.2.10` 可限定目标主机，`-w capture.pcap` 可保存文件，供 Wireshark 分析。

怎么看结果

适合服务器没有图形界面时观察是否真的发出了数据包。看到了请求却没有响应，仍需结合防火墙、服务端日志与路径排查，不能直接归咎于某一端。

使用前要注意

抓包通常需要较高权限；限制时间与抓包范围，避免无意记录其他人的数据。示例 IP 为文档保留地址。
