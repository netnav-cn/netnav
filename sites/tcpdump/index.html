tcpdump 的定位并不复杂：经典命令行网络抓包工具。真正有用的是先确认 tcpdump 和眼前的问题是不是同一类。

用 tcpdump 调试时，别把真实密钥带进去

用 tcpdump 调试时尽量先用测试数据，尤其是令牌、Cookie、密钥和生产请求，不要为了方便直接放进不熟悉的在线环境。

tcpdump 是命令行抓包工具，适合按接口、主机、端口或协议过滤网络数据包。排查底层连接问题时很有用，但它不是用来手动构造 API 请求的客户端。

推广

如果要长期用，可以留意这些

  • 先在测试环境或测试数据上操作。
  • 不要把真实密钥和令牌直接粘贴进陌生在线工具。
  • 会修改请求或流量的功能，先确认影响范围。
