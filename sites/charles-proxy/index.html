Charles Proxy

HTTP/HTTPS 调试代理工具。

核心用途：Charles Proxy 是桌面网络代理调试工具，可以查看经过代理的 HTTP 请求、响应和时间信息，常用于网页及移动 App 接口排查。

先确认流量是否经过代理

为要测试的设备或应用设置正确的代理地址和端口，再观察 Charles 是否收到请求。HTTPS 内容的解密需要额外的证书信任配置；仅在明确授权的测试设备上启用。

区分网络报错和应用报错

连接失败、代理证书不受信任、接口返回 401/403 是不同层次的问题。优先检查代理连通性和信任设置，再核对认证头、请求体及服务端响应；日志可能包含私人数据，分享前应脱敏。
