DNSChecker

DNSChecker 可对比不同地区递归 DNS 的解析结果。适合核对 A、AAAA、MX 等记录更新，但不能代替权威 DNS 检查。

查询什么

DNSChecker 可以从不同解析节点查询域名记录，适合在更换 A、AAAA、CNAME 或 MX 记录后观察多地解析结果是否一致。

一次检查怎样做

输入完整域名并选择正确记录类型，把返回值与预期配置逐一比对。若结果不同，先直接查询权威名称服务器的当前记录，再检查 DNS 缓存与 TTL，避免频繁改动已经正确的记录。

不能把所有差异叫传播失败

递归解析器可能缓存旧值，部分节点也可能发生超时或故障。网站是否真的可访问，还取决于 HTTPS 证书、CDN、源站与网络路径，不能只凭 DNS 查询结果判断。
