Nmap 解决什么问题

Nmap 是网络发现和端口扫描工具。它可以帮助管理员确认自己管理的设备有哪些端口在监听、某项服务是否可以从测试位置访问；并不是 API 请求调试器。

先用小范围端口测试

在自己管理或已获得明确授权的主机上，可以使用 nmap -sT -p 80,443 example.com 检查指定 TCP 端口。先确定目标和端口范围，再考虑是否有必要探测更多服务；避免在未知环境使用大规模扫描。

怎样理解结果

open 表示测试时端口接受连接，closed 表示目标可达但端口没有对应监听，filtered 通常意味着报文可能被过滤。扫描视角、主机防火墙和目标网络策略都可能影响结果；开放端口本身不能证明存在安全漏洞。

扫描边界

扫描会发送真实流量。仅在授权范围内执行，并控制频率；生产环境的变更与安全评估需要结合服务日志、配置核验和其他证据。
