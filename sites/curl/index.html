直接检查 HTTP 响应

使用 `curl -I https://example.com/` 查看响应头，或 `curl -v https://example.com/` 观察连接与 TLS 握手过程；需要了解重定向链时可结合 `-L` 并注意最终访问地址。

怎么看结果

先区分 DNS 解析错误、连接超时、TLS 证书验证失败及 HTTP 4xx/5xx。服务器返回 200 也不意味着网页中的全部脚本和资源都能正常工作。

使用前要注意

不要在共享终端记录含有令牌的完整命令；处理包含凭据的 URL 或 Header 时尤其要注意日志泄露。
