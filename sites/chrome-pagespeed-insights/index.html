用 PageSpeed Insights 检查网页性能

输入页面 URL 后，先区分真实用户体验数据与实验室模拟测试。Core Web Vitals 包括 LCP、INP 和 CLS，报告里可查看哪些资源或操作影响性能。

使用前需要注意

实验室分数会随测试环境变化；没有足够真实用户数据时也可能不显示现场指标。优化前先判断是图片、脚本、字体还是布局问题，不要只追求单次满分。
