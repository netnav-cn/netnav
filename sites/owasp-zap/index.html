OWASP ZAP

开源 Web 安全测试代理。

快速判断：开源 Web 安全测试代理。
类型
开发者网络工具
网站
zaproxy.org

在授权环境中检查 Web 安全问题

先通过浏览器代理方式检查请求与响应，再在测试环境使用被动扫描了解可能的风险。主动扫描会发送额外请求，应确认范围、凭证和业务影响后再进行。

怎么看结果

扫描告警需要人工复核，误报和漏报都可能存在；没有扫描结果不意味着系统安全。

使用前要注意

仅测试自有或明确授权的网站。生产系统中的主动扫描可能影响性能或触发业务操作。

进一步排查可参考：网络工具使用安全
