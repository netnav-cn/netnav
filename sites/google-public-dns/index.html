Google Public DNS 是什么

Google Public DNS 提供公共域名解析服务，可作为设备或路由器的 DNS 解析器。使用它不等于启用了 VPN，也不会对所有应用流量进行加密。

配置前确认网络要求

先检查公司或校园网络是否有指定 DNS 以及过滤策略。修改设备配置时记录原值，以便恢复；如果浏览器启用了独立的安全 DNS，浏览器的实际解析路径可能与系统设置不同。

怎样检查是否生效

修改后用系统 DNS 查询工具对照指定解析服务器获得的结果，并检查浏览器的 DNS 配置。递归解析缓存与本地缓存可能影响短时间内的结果，不宜仅凭一次网页加载快慢评价解析器。

什么时候不值得更换

下载慢、游戏延迟高或网站服务器无响应，不一定由 DNS 引起。只有解析错误、明显解析不稳定或需要特定解析策略时，调整 DNS 才更可能解决问题。
