Cloudflare DNS Checker

检测是否正在使用 Cloudflare DNS。

适合做什么：查看域名 DNS 解析相关信息，用于辅助定位记录设置与解析结果异常。

先核对记录类型

输入正确域名，分别确认 A/AAAA、CNAME 或 MX 等记录是否符合当前业务。若刚修改记录，应先查看权威 DNS 设置，再比较公共解析器结果。

解析正确不代表网站正常

DNS 返回预期 IP 只能说明名称解析环节可用，服务器端口、证书和应用仍可能出错。若网站打不开，请进一步检查 HTTP 响应和实际连通性。
