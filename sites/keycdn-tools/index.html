适合临时做一轮网络检查

KeyCDN Tools 把 Ping、Traceroute、DNS 查询、HTTP Header 等常见工具放在一起。临时排查某个域名、IP 或网站响应时，不想开终端可以直接从这里开始。

KeyCDN Tools 更适合用来缩小问题范围

KeyCDN Tools 更适合看连续结果和前后变化。一次超时或一次高延迟未必能说明真正的故障位置。

推广

KeyCDN Tools 用起来前，先过一遍这些

  • 打不开网站：先查 DNS，再看 HTTP 响应。
  • 怀疑线路：用 Ping 和 Traceroute 做对照。
  • 怀疑缓存或跳转：查看状态码和响应 Header。
