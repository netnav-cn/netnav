IPLeak 可用来观察页面检测到的公网 IP 以及 DNS 等相关信息。连接代理或 VPN 后，可以比较显示地址是否符合你的预期。

重点检查什么

WebRTC、DNS 和公网 IP 属于不同层面的信息；某项检测显示多个地址不必然意味着所有流量暴露。应先确认网络设置和测试项目各自代表什么。

不要误判

记录未连接 VPN 时的结果，连接后刷新再对比；分别测试不同浏览器，并注意浏览器安全 DNS 功能可能与系统设置不同。
