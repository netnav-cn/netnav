httpbingo

HTTP 测试与回显服务。

用途：httpbingo 提供 HTTP 请求回显接口，可用来查看请求方法、参数、请求头和响应行为，适合开发与联调。
类型
浏览器网络工具
网站
httpbingo.org

如何做基础测试

浏览器打开 `/get` 可查看 GET 请求相关信息；需要验证 POST 请求时，可用 curl 或 API 客户端发送测试数据，再检查返回的 JSON。

它不能解决什么

HTTP 回显服务不是浏览器匿名性检测，也不能证明网站真实业务接口的性能或安全性。测试结果仅说明此次请求如何到达该服务。

避免上传敏感数据

公共回显服务不适合发送真实令牌、会话 Cookie、客户资料和生产机密。测试时用占位符和脱敏样本。
