Cloudflare 1.1.1.1：公共 DNS 怎么设置与验证

它是什么

1.1.1.1 是 Cloudflare 提供的公共 DNS 解析服务。把设备的 DNS 服务器指向 1.1.1.1，可让域名查询交给该解析器处理。它不负责提供 IP 归属地、ASN 查询，也不会替你隐藏全部上网流量。

配置前看清楚

可以按照 Cloudflare 官方的系统或路由器教程，选择普通 DNS、DNS over HTTPS 或 DNS over TLS 等方式。不同系统的设置入口与加密 DNS 支持情况不同；建议记下原先的 DNS 设置，以便出现兼容问题时恢复。

怎么验证

完成设置后，用系统的 DNS 查询工具确认当前解析器及域名解析是否正常；浏览器启用加密 DNS 时，还应检查浏览器自己的 DNS 配置。只看到 1.1.1.1 的地址不一定能证明整个设备所有应用都采用相同方式解析。

哪些问题它解决不了

切换 DNS 可能改变域名解析的延迟或结果，却不能直接改善拥塞、Wi-Fi 干扰、运营商线路故障，也不代表获得 VPN 的完整流量保护。
