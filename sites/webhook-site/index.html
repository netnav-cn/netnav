Webhook.site

Webhook.site 提供临时接收 URL，方便检查 Webhook 和 HTTP 回调请求的内容。

适合调试什么

把测试系统的回调地址指向临时 URL，可以检查请求方法、请求头、请求体和发送时间。适合确认对方是否真的发起请求，以及请求格式是否符合预期。

不要直接发送真实秘密

临时公开接收端不适合承载真实访问令牌、身份证件或客户数据。调试时应使用测试环境、脱敏载荷，并留意临时 URL 的访问权限和有效期。

确认回调后还要做什么

收到请求只表示发送端已触发调用，不等于正式业务接口能够正确处理。完成结构检查后，仍要对真实应用的签名校验、重试和幂等处理进行测试。
