按加载过程定位页面瓶颈

用相同的网络、设备和测试位置进行多次测试，重点查看瀑布图中耗时较长的请求、首字节时间和渲染过程；区分首次访问和重复访问。

怎么看结果

单次测试异常可能受节点、网络波动和缓存影响。实验室结果适合诊断，不应直接当作真实用户 Core Web Vitals。

使用前要注意

优化时先处理真正影响主要内容呈现的资源，避免盲目压缩所有文件。
