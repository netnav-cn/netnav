AdGuard DNS：DNS 层广告过滤如何使用

了解 AdGuard DNS 的解析和过滤功能、配置验证与兼容性限制，不要把它当作 IP 定位查询工具。

主要用途

AdGuard DNS 在域名解析层提供广告、跟踪或部分恶意域名过滤选项。它不会像浏览器内容拦截器那样识别页面中的每一个广告元素，对使用自有域名或应用内嵌内容的情况也可能无法完全处理。

怎么开始

根据官方文档选择公开解析器或可配置方案，确认设备支持普通 DNS、DoH 或 DoT 中哪一种，再按相应步骤配置。配置前先保存原地址，便于排查兼容性。

验证过滤是否生效

测试一个普通域名能否解析，再使用官方提供的检测方式核对 DNS 配置。如果某些内容消失或应用异常，应结合过滤规则逐步排查，不要把所有连接问题归因于 DNS。

与泄漏检测工具的区别

AdGuard DNS 是实际处理 DNS 解析的服务；DNSLeakTest 等工具负责观察请求经过哪个解析器，不能代替 DNS 设置。
