适合反复调试接口的工作

Insomnia 可把请求按项目组织起来，便于重复发送 HTTP 请求、查看响应头和响应体，并比较测试环境与生产环境的行为。它并不代替后端服务的日志和自动化监控。

一次请求怎么排查

先确认方法和 URL，再检查查询参数、认证方式、Content-Type 与请求体格式。收到 401/403 时优先看授权，400/422 往往需要核对请求数据，5xx 则应结合服务端日志判断。

环境变量与共享注意事项

不同环境的域名与令牌应分开管理。导出工作区或分享请求时，先确认凭据没有跟随文件一起泄露；公共回显服务也不应接收真实生产密钥。

对照其他工具

需要命令行复现时可以比较 curl，检查原始 HTTP 请求回显可使用 httpbin。
