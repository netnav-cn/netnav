简单说，Mullvad DNS 解决的是这一件事：Mullvad 提供的公共加密 DNS 信息。确定 Mullvad DNS 的方向没跑偏，再打开官网看具体功能会更高效。

用 Mullvad DNS 前，先确认你查的是哪一层

用 Mullvad DNS 查询时，先确认输入和输出分别属于哪一层网络信息。用 Mullvad DNS 时，DNS 记录、IP 归属和 ASN 要分开理解。

推广

如果要长期用 Mullvad DNS，这些细节很实用

  • 先确认查询的是域名、IP 还是 ASN。
  • 改 DNS 后要考虑缓存和传播时间。
  • Mullvad DNS 如果显示归属地，把它当作数据库信息而不是精确定位。
