Mullvad DNS

Mullvad DNS 是 DNS 解析服务，不是 VPN。了解加密 DNS、可选过滤配置和隐私边界。

DNS 服务不等于 VPN

Mullvad DNS 用于域名解析，部分服务入口提供加密 DNS 与过滤选项。它不会像 VPN 那样接管所有应用的网络流量，也不能仅靠换 DNS 隐藏公网出口 IP。

选用前确认什么

从官方文档获取当前可用的 DoH 或 DoT 地址，按设备或浏览器支持的协议设置。留意不同过滤配置会影响哪些域名；配置后分别测试解析结果和实际网页访问。

隐私边界

加密 DNS 保护的是设备与解析服务之间相应的 DNS 通信，不会替其他应用建立完整的加密隧道。对日志和数据保留的判断，务必查看服务商最新政策。
