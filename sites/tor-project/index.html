Tor Project 与 Tor Browser 有什么区别

Tor Project 维护 Tor 匿名通信网络与相关软件；Tor Browser 是面向普通用户的浏览器入口。

项目与产品不是一回事

Tor Project 是 Tor 网络及相关开源软件的维护组织和项目；Tor Browser 是其中较为常见的用户端产品。想使用浏览器应进入官方 Tor Browser 下载入口，不必把项目站点误当作通用 VPN 服务。

Tor 网络能提供什么

Tor 通过多节点转发帮助降低网站直接观察用户来源网络的能力，但这不等于无条件匿名，也不意味着所有应用默认受保护。具体行为取决于使用的软件和设置。

如何了解与使用

普通用户可从官方文档了解 Tor Browser 的支持平台和连接方式；开发者或研究者可阅读 Tor 网络及安全资料。不要使用来历不明的第三方安装包。
