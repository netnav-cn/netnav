查 IP 时能看到什么

IPinfo 用于查询公网 IP 的网络归属、ASN 和地理位置相关资料，适合网络诊断和了解请求可能来自哪个运营网络。

怎样理解结果

IP 地理位置通常是估计值，不能据此确定某个人的真实住址。代理、云服务和移动网络都可能使地理位置与用户所在地不同。

排查使用场景

发现访问被地区限制或风控误判时，可记录公网 IP 与 ASN 作为诊断线索，再结合出口网络和服务端日志判断。
