诊断思路

Check-Host 让你从不同网络位置检查目标服务的连通情况，适合区分“只有我这里访问失败”与“多地都存在问题”。

读结果的重点

先确认 DNS 是否解析到预期地址，再看 HTTP 返回状态、连接超时和不同地区差异。个别节点异常不等于网站全球宕机。

别忽略的限制

不同检测节点使用的网络路径可能不同，结果只能作为线索。涉及故障定位时与站点自身监控日志一起判断。

一次多地区故障排查怎么读

若各地区 DNS 都正确但 HTTP 只有部分地区超时，可以进一步查看 CDN、区域路由或源站访问控制；如果各地均返回同一 5xx 状态，优先检查服务器或上游代理日志。反过来，Ping 不通但 HTTPS 正常时，可能只是目标限制了 ICMP。
