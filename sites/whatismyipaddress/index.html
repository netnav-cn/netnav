WhatIsMyIPAddress

IP 地址与网络信息查询。

适合做什么：查询公网 IP 及常见归属信息，适合对比不同网络出口和排查位置识别差异。
类型
DNS 与 IP
网站
whatismyipaddress.com

先确认出口地址

在同一设备上分别用家庭网络和手机网络打开页面，记录显示的 IP。使用 VPN 时再查看一次，可以观察网页实际看到的出口是否改变。

归属地和真实位置不同

运营商名称、城市或地图定位通常来自第三方 IP 数据库，不是实时 GPS。不要凭城市不一致就认定账户异常；如要确认网站访问故障，应结合 DNS 和连通性测试。
