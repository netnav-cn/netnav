下载一个文件

在终端执行 wget 后跟随可信文件 URL，可将远程资源保存到本地。使用 -O 可以指定输出文件名；如果 URL 包含特殊字符，建议用引号包裹，避免 Shell 将其误当作操作符。

中断后怎样继续

对支持范围请求的服务器，可用 wget -c URL 尝试继续未完成的文件；是否能续传取决于服务端支持和远端文件是否变化。下载完成后对照发布方提供的校验值，比仅确认文件大小更可靠。

批量下载时的边界

下载前确认版权和访问授权，限制请求速度与并发，避免过度请求影响对方服务。不要把带密钥的下载 URL 原样贴进公共日志或截图；跟随重定向时也应核实最终域名。
